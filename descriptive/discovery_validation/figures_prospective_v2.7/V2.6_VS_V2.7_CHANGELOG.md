# v2.6 → v2.7 Changelog

**Nature of this revision:** visual / plotting-only. No scientific, statistical,
or membership change. All numerical values, protein IDs, P values, BH-FDR,
CIs, Model_status, and display-selection memberships are identical to v2.6
(verified programmatically; see VISUAL_QC.md and invariance check).

---

## 1. Typography (visual/style)
- **Family:** switched to Arial throughout (was system default / sans-serif mix).
- **Base size:** 6.5 pt → 7.5 pt; axis/legend text 6.8 pt; panel tags 9 pt bold.
- **Bold removal:** strip.text and plot.title no longer bold (was bold in v2.6).
- **Strip background:** unified to `#F2F2F2`.

## 2. Color system (visual/style)
- Introduced a fixed, colorblind-safe semantic palette (Okabe-Ito derived):
  - Control `#6E6E6E`, Low `#4C9BB8`, High `#C4573B`,
    Humid-hot `#A64D6A`, High-altitude `#3D8B7A`,
    Discovery `#2E6FA8`, Validation `#C49A3D`.
- **Bug fix (v2.6 color collision):** v2.6 used `#3274A1` for BOTH "Discovery"
  AND "High-altitude"; v2.7 separates them. Low `#3B82A0` was also near-duplicate;
  replaced with `#4C9BB8`.
- Site palette: replaced v2.6's rainbow 6-site palette (pink/orange/green/cyan/
  blue/magenta) with a restrained non-rainbow qualitative set.
- Reference lines: unified to dashed `#9A9A9A`.
- Background/non-significant points: neutral `#C4C4C4`.
